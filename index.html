Staggered booking: each 15-minute block (e.g. 08:00–08:15) holds up to 5 patients across the 8 consultation rooms — a block is blocked outright once full. New case ≈ 30 min · Follow-up ≈ 15 min consultation. Session totals above are a separate daily ceiling: booking beyond the overflow ceiling is blocked; between the standard limit and ceiling requires a confirm step. Special Clinic and Other (visiting) clinics can also offer the 14:00–17:00 afternoon session on the day they're booked, since they don't run on one fixed weekday the way Neonatal/Paediatric/Community/Weight Gain do.

Staggered booking blocks (example)

Morning: 08:00–08:15, 08:15–08:30 … through 11:45–12:00 (16 blocks). Afternoon: 14:00–14:15 … through 16:45–17:00 (12 blocks) — always available for the Paediatric Clinic (Wed), and available on request for Special Clinic and Other (visiting) clinics on the day they're booked. Each block: max 5 patients, 8 rooms available.

Settings

Connect this system to a Google Sheet so it saves automatically

Google Sheet connection

This connects to a small Google Apps Script "Web App" bound to your MOH Google Sheet. Every change here is pushed to the Sheet automatically, and the Sheet's data is pulled in when you connect.

⚠ Treat the Web App URL and secret like a password. You only type them once per device — they are then remembered in this browser (not in the page link or the file). Use Disconnect to remove them from a shared computer.

One-time setup (Apps Script)

  1. Open your MOH Google Sheet → Extensions → Apps Script.
  2. Delete the default code and paste in the Code.gs file provided alongside this app.
  3. Replace SECRET at the top with a password only your clinic knows.
  4. Click Deploy → New deployment → Web app. Set "Execute as: Me" and "Who has access: Anyone with the link".
  5. Copy the Web App URL it gives you and paste it above, with the same secret key.
  6. Click Connect & sync now. This browser remembers the connection and reconnects automatically every time the scheduler is opened — repeat this step once on each new computer, phone or browser.

Home-screen icon check

Phones only show the app icon on a home-screen shortcut if these files are on the website in the same folder as this page. This checks the live site right now.

Load testing

Fills today's clinic with a large batch of realistic dummy patients and appointments spread across the day, so you can try out the Dashboard, Appointments, and Reports views under a busy-day volume. Safe to run any time — everything it adds is tagged and can be removed with one click.
